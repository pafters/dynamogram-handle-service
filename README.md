## Описание

Сервис автоматической выгрузки динамограмм с динамографа в SQL-таблицу базы данных.

Реализованный функционал:

1. Модуль получения файлов динамограмм из КСУ на сервер по системному крону.
1. Модуль вызова команды считывания динамограммы из динамографа КСУ по настройке крона, хранящейся в базе данных.
1. Модуль конвертации файлов динамограмм из base64 в записи таблицы базы данных.

## Установка зависимостей

```bash
$ npm install
```

## Необходимые компоненты для корректной работы сервиса

1. Valkey.
1. PostgreSQL -v >= 17.0.
1. Node.js -v >= 20.0.0.

## Запуск проекта

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run build
```
